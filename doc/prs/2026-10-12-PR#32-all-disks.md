# PR#32: A Chart for Each Disk of a Werkator

> **WARNING:** This document describes only the change applied in this PR.
> It may already be outdated once the next PR is merged.
> Historic PR documentation is not maintained along with new PRs; treat it as a snapshot.

## Problem

A Werkator panel charts only the first disk of the host.
Werkator javagil has two, SSD and HDD; a full HDD stays hidden.

## Non-Goals

- No limit on the number of disks; a Werkator has one or two.

## Specification

### Feature: Werkator panel with all disks

#### Scenario#32.01: each disk has its chart

&hellip; so that a full disk shows, whichever it is.

- **Given** a Werkator with the disks SSD and HDD
- **When** the user opens the overview
- **Then** its panel shows a chart for SSD and one for HDD, in Werkator's order

##### Verified by

- [WerkatorSourceTest](../../dashboard/src/test/kotlin/de/hoennig/werkregie/dashboard/sources/WerkatorSourceTest.kt):
  "the load holds the fixed charts with their levels".

## Solution

- `WerkatorSource` makes a chart for each disk of `/api/system`, between RAM and load.
- Version 0.13.0.
