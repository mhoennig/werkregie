## Problem

`mi` writes the purpose line of a scenario as `&hellip; so that …`, in lower case after the ellipsis,
so that it continues the scenario title.
`doc/prs/TEMPLATE.md` of werkregie does so since werkregie PR#12;
the shared `doc/agentic-workflow.md` still asks for a "So that …".

## Non-Goals

- No change of older PR documents; they are snapshots.
- No change of the other repositories; each one takes the new text over with its next PR.

## Solution

- `doc/agentic-workflow.md`: each scenario has a purpose line `&hellip; so that …`, in lower case after the ellipsis.
- Version 0.7.2.
